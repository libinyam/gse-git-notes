Git 可视化讲解

项目是由原子变更推进的快照，可以分支，可以合并。——在浏览器里敲命令，看图变化

数据模型

blob
文件内容本身，不含文件名
tree
目录：名字 → blob 或子 tree
commit
父提交 + 元信息 + 顶层 tree
引用
名字 → commit 哈希；分支、HEAD、标签都是引用，也是唯一会变的东西

每条命令都可以翻译成：往对象库里加了什么，挪了哪个引用。
